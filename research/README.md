## Key Findings

### Market Gap
**No dedicated BYOK AI image tool exists.** TypingMind/Msty focus on chat. Wide open opportunity.

### Recommended Stack
- **Provider**: Together AI (single API, 20+ models, $0.003/image)
- **Pricing**: $29 / $59 / $149 LTD
- **Free Hook**: Background removal + 5-10 free images/day

### User Pain Points
1. 💰 Subscription fatigue ($30/month is "a week of food")
2. 🔒 Privacy ($60/month for Midjourney "stealth mode")
3. 😤 Credits expire, don't roll over
4. 🚫 Censorship blocking legitimate use cases
5. 🔌 No API for developers

### Marketing Angles
- "Pay once, own forever"
- "Your images, your privacy"
- "80% cheaper than subscriptions"
